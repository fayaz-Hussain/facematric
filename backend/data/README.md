# Data Directory

This directory contains model files and precomputed embeddings required for FaceMatric backend.

## Required Files

### 1. `face_landmarker.task` (MediaPipe Face Mesh Model)

**Purpose**: MediaPipe Face Mesh model for detecting 468 facial landmarks.

**Download**: 
- Visit [MediaPipe Face Landmarker](https://developers.google.com/mediapipe/solutions/vision/face_landmarker#models)
- Download the "face_landmarker.task" file
- Place it in this directory

**Size**: ~26 MB

**License**: Apache 2.0

---

### 2. `celebrity_embeddings.pkl` (Celebrity Face Embeddings)

**Purpose**: Precomputed FaceNet embeddings for 205 celebrities (105 Western + 100 Bollywood).

**Generation**: This file will be generated by running Task 12 (Celebrity Database Preprocessing):

```bash
python scripts/preprocess_celebrity_database.py
```

**Contents**:
```python
{
    "celebrity_name": {
        "embedding": np.array([...]),  # 128-dimensional FaceNet vector
        "dataset_source": "Western" or "Bollywood",
        "thumbnail_path": "path/to/thumbnail.jpg",
        "image_count": 5  # Number of images averaged
    },
    ...
}
```

**Size**: ~2-3 MB

**Note**: This file must be generated from the `celebrity_dataset/` folder before running the backend with celebrity matching enabled.

## Celebrity Database Source

The celebrity embeddings are generated from images in:
```
../celebrity_dataset/
├── Aamir_Khan/
├── Abhay_Deol/
├── Abhishek_Bachchan/
└── ... (275 celebrity folders)
```

**Dataset Composition**:
- **Western Celebrities**: 105 celebrities (Pins Face Recognition dataset)
- **Bollywood Celebrities**: 100 celebrities

---

## Generation Script Location

The preprocessing script will be created in:
```
backend/scripts/preprocess_celebrity_database.py
```

Run it with:
```bash
cd backend
python scripts/preprocess_celebrity_database.py
```

This will:
1. Scan all celebrity folders
2. Generate FaceNet embeddings for each image
3. Average embeddings per celebrity
4. Save to `celebrity_embeddings.pkl`

---

## Notes

- **Privacy**: Only celebrity images are stored in embeddings. User images are never persisted.
- **Updates**: To add new celebrities, simply add their folder to `celebrity_dataset/` and regenerate the embeddings.
- **Fallback**: If `celebrity_embeddings.pkl` is missing, celebrity matching will be disabled, but golden ratio scoring will still work.
