=====================================
WHAT EACH COMPONENT DOES
=====================================

1. IMAGE PROCESSOR (39 tests)
   Input:  Any image file (JPEG, PNG, etc.)
   Process: Format detection, EXIF rotation, color normalization, 
            resize to 640px max, JPEG compression
   Output: Normalized RGB image
   Test:   pytest tests/unit/test_image_processor.py -v

2. FACE DETECTOR (29 tests)
   Input:  Image with face
   Process: MediaPipe Face Mesh detection
   Output: 468 3D facial landmarks + confidence
   Errors: No face, multiple faces, poor quality, occlusions
   Test:   pytest tests/unit/test_face_detector.py -v

3. SYMMETRY CLASSIFIER (49 tests)
   Input:  468 facial landmarks
   Process: Measure face dimensions, apply decision tree
   Output: Face shape (oval/rectangle/round/square/heart/diamond)
   Test:   pytest tests/unit/test_symmetry_classification.py -v

4. GOLDEN RATIO SCORER (51 tests)
   Input:  468 facial landmarks
   Process: Measure 8 ratios, score against φ=1.618
   Output: Overall score (0-100) + 8 feature breakdowns
   Test:   pytest tests/unit/test_golden_ratio_scorer.py -v

5. PERCENTILE ENGINE (50 tests)
   Input:  Golden ratio score (0-100)
   Process: Convert to percentile using CDF
   Output: Percentile rank (0-100)
   Test:   pytest tests/unit/test_percentile_engine.py -v

6. OVERLAY GENERATOR (28 tests)
   Input:  468 3D facial landmarks
   Process: Convert to 2D, calculate guides
   Output: 2D landmarks + phi guide coordinates
   Test:   pytest tests/unit/test_extract_2d_landmarks.py -v

7. COSINE SIMILARITY (30 tests)
   Input:  Two 512-dim embedding vectors
   Process: Compute dot product / (norm1 * norm2)
   Output: Similarity score (-1 to 1)
   Test:   pytest tests/unit/test_cosine_similarity.py -v
