==============================================
HOW TO RUN TESTS
==============================================

1. Install dependencies:
   cd backend
   pip install -r requirements.txt

2. Run all tests:
   pytest tests/unit/ -v

3. Run specific component tests:
   pytest tests/unit/test_image_processor.py -v
   pytest tests/unit/test_face_detector.py -v
   pytest tests/unit/test_golden_ratio_scorer.py -v
   pytest tests/unit/test_percentile_engine.py -v

4. Run with coverage:
   pytest tests/unit/ --cov=app --cov-report=html

5. Run specific test:
   pytest tests/unit/test_golden_ratio_scorer.py::TestRatioMeasurements -v
